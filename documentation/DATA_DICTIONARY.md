# Data Dictionary — MarketPulse India

## 1. Raw AGMARKNET Dataset (`raw_history`)
Source Parquet file: `data/raw/all_market_history.parquet` (localized snapshot from AGMARKNET)
Total Rows: **1,481,324**  
Coverage Period: **30 August 2024 to 28 September 2026** (760 unique dates)  

| Column Name | Physical Data Type | Semantic Type | Description & Domain | Typical Units |
| :--- | :--- | :--- | :--- | :--- |
| `state_id` | `int64` | Identifier | Government state code (e.g. 2: AP, 16: KA, 17: KL, 20: MH, 31: TN, 32: TG) | Integer |
| `state` | `string` | Categorical | State name (6 unique states) | Text |
| `district` | `string` | Categorical | Administrative district name (176 unique districts) | Text |
| `market_id` | `string` | Persistent ID | Unique APMC market identifier format `state_id-mandi_id` (1,537 unique mandis) | Code |
| `market` | `string` | Label | Reported market name string (1,741 variants due to historical naming shifts) | Text |
| `commodity` | `string` | Categorical | Agricultural commodity name (14 core commodities) | Text |
| `date` | `date32` | Temporal | Market trading day (YYYY-MM-DD) | Date |
| `min_price` | `double` | Metric | Minimum auction price recorded for the commodity on that day | ₹/Quintal |
| `max_price` | `double` | Metric | Maximum auction price recorded for the commodity on that day | ₹/Quintal |
| `representative_price` | `double` | Metric | Modal (most frequent) or arrival-weighted mean price across lots | ₹/Quintal |
| `arrivals_tonnes` | `double` | Metric | Total physical arrivals unloaded in the market yard on that day | Metric Tonnes |
| `variety_count` | `int64` | Count | Number of distinct varieties traded in the market on that day (1 to 8) | Count |
| `example_variety` | `string` | Categorical | Variety with largest reported arrival share (e.g. 'Unhali', 'Red', 'Other') | Text |
| `example_variety_basis` | `string` | Metadata | Criterion for selecting representative variety | Text |
| `aggregation_method` | `string` | Metadata | Aggregation method (e.g. 'arrival-weighted mean of variety modal prices') | Text |
| `arrival_coverage` | `string` | Metadata | Arrival reporting completeness status ('complete') | Text |
| `anomaly_score` | `double` | Metric | Statistical outlier score based on rolling IQR / z-score | Standard deviations |
| `is_anomaly` | `bool` | Flag | Boolean flag indicating whether anomaly score exceeded threshold | True/False |

## 2. Standardized Analytical View (`vw_clean_market_history`)
Generated by `src/cleaning/pipeline.py`. Preserves all raw fields while attaching canonical entities and audit flags:

| Column Name | Semantic Type | Transformation / Business Logic |
| :--- | :--- | :--- |
| `canonical_market_name` | Entity Invariant | Standardized market name mapping historical text shifts to persistent `market_id` (e.g. `20-161` $\to$ `Lasalgaon APMC`, `20-2703` $\to$ `Mumbai-Onion & Potato Market APMC`) |
| `modal_price_quintal` | Metric | Alias for `representative_price` in standard ₹/Quintal (1 Quintal = 100 kg) |
| `modal_price_kg` | Derived Metric | `modal_price_quintal / 100.0` in ₹/kg |
| `arrivals_quintals` | Derived Metric | `arrivals_tonnes * 10.0` in Quintals |
| `standardized_variety` | Categorical | Standardized cultivar label (e.g. maps blank, 'n/a', 'other' to 'Other / Unspecified') |
| `variety_granularity` | Categorical | 'Specific Variety' (e.g. Unhali, Red, Local) vs 'Generic Other' |
| `is_valid_price` | Quality Flag | True if `representative_price >= ₹10/quintal` and `min_price <= max_price` |
| `is_valid_arrival` | Quality Flag | True if `arrivals_tonnes > 0` |
| `record_quality_status` | Quality Categorical | 'VALID', 'SCALE_ERROR_LOW_PRICE', 'INVERTED_PRICE_RANGE', 'ZERO_ARRIVALS' |

## 3. Unit Conversion Standards

$$\text{1 Metric Tonne (MT)} = 1,000 \text{ kg} = 10 \text{ Quintals}$$
$$\text{1 Quintal (Qtl)} = 100 \text{ kg} = 0.1 \text{ Metric Tonnes}$$
$$\text{Price in ₹/kg} = \frac{\text{Price in ₹/Quintal}}{100}$$
